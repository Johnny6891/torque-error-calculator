# 扭力誤差計算器 (Torque Error Calculator)

一個純前端的單頁工具，用來計算**扳手扭力**相對於**儀器扭力**的誤差百分比，適用於扭力扳手校驗紀錄。

## 功能

- 兩個僅限數字的輸入框:「扳手扭力」與「儀器扭力」
- 輸入時即時計算誤差百分比,公式:

  ```
  誤差 % = (扳手扭力 ÷ 儀器扭力 − 1) × 100
  ```

  四捨五入取至小數第 2 位顯示
- 點擊「新增紀錄」(或按 Enter)將當前數值與誤差加入最上方的紀錄列表,並清空輸入框
- 新紀錄顯示在上一筆下方,最多保留 10 筆,超過時最舊的一筆自動移除
- 儀器扭力為 0 或欄位空白時不計算、按鈕停用,避免除以零
- 響應式設計,支援行動裝置(窄螢幕時紀錄改為直向排列,輸入框帶出數字鍵盤)

## 使用方式

不需安裝任何東西,直接用瀏覽器開啟即可:

```
index.html
```

雙擊檔案,或拖曳到任一現代瀏覽器(Chrome、Edge、Firefox、Safari)中使用。
